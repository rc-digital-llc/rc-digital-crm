<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| JSON/user text → branded value | Untrusted tokens could smuggle unsafe numbers or malformed values into authority. |
| Exact intermediate → persisted minor units | Overflow or implicit rounding could change an authoritative result. |
| Policy name → arithmetic behavior | A default or mismatched policy could make replay nondeterministic. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | wire parser | mitigate | String-token type checks, closed grammar, canonicalization, boundary tests. |
| T-03-02 | Tampering | JS arithmetic | mitigate | Private branded constructors and `BigInt`-only authoritative API. |
| T-03-03 | Tampering / Repudiation | rounding | mitigate | Explicit immutable policy identifiers and signed golden/property vectors. |
| T-03-04 | Denial of Service | oversized input | mitigate | Nine-digit rate precision, bounded grammar length, checked output range. |
| T-03-SC | Tampering | dependencies | mitigate | No package addition; native runtime and locked existing toolchain only. |
</threat_model>
