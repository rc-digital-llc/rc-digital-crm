<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Authenticated caller → SECURITY DEFINER read RPC | Definer privilege must never substitute for caller-derived row authority. |
| RPC request → pagination/filter/order | Client keys could inject SQL, widen tenant scope, or exhaust resources. |
| Legacy decimals/JSON → exact authority | Ambiguous or fractional values could be guessed or rounded. |
| Idempotency key/effect context → automation/evidence state | A conflicting request could be mistaken for an identical replay. |
| Historical migration → replacement definition | Editing accepted evidence history could hide a breaking cutover. |
| New/changed tests → protected targets | Test 65 or inherited evidence/replay proof could be skipped. |
