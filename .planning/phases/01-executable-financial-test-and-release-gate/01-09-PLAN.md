<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR/merge-group code → GitHub runner | Untrusted changes execute tests but must not gain write/deploy secrets. |
| Workflow job names → ruleset | Renaming/skipping a check could silently remove merge authority. |
| Checked-in ruleset → live GitHub settings | Source intent is not protection until authenticated API state matches. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | required checks/ruleset | mitigate | Exact independent identities, merge queue, no bypass, live API readback. |
| T-01-02 | Repudiation | path/skipped checks | mitigate | Paths affect PR early feedback only; all merge-group lanes unconditional. |
| T-01-03 | Information Disclosure | PR jobs | mitigate | Read-only permissions, isolated local stack, no production environment/secrets. |
| T-01-SC | Tampering | workflow actions | mitigate | Full-SHA action pins and exact Supabase CLI 2.115.0. |
</threat_model>
