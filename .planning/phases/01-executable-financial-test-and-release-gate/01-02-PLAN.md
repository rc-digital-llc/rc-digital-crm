<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authenticated caller → `SECURITY DEFINER` RPC | Caller-controlled lead ID crosses into privileged database execution. |
| Migration files → blank database | Repository SQL can create, alter, grant, or expose every application object. |
| Schema push script → database URL | A misresolved target could mutate shared or production state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-01-04 | Tampering | migration chain | mitigate | Blank replay, exact history comparison, live view/RPC assertions, and no assertion retry. |
| T-01-05 | Elevation of Privilege | `convert_lead_to_contact` | mitigate | `auth.uid()` ownership, locked search path, schema qualification, narrow grants, cross-owner pgTAP denial. |
| T-01-06 | Tampering | schema push target | mitigate | Parse and require loopback/test scope; prohibit linked/access-token modes. |
| T-01-SC | Tampering | Supabase CLI | mitigate | Use the Plan 01 pinned CLI contract; no package install is added here. |
</threat_model>
