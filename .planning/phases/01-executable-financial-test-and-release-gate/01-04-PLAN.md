<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| JWT claims → PostgreSQL RLS/RPC | Caller identity and role claims determine row/function authority. |
| HTTP response → test assertion | Status-only checks could miss unauthorized effects or leaks. |
| Test service key → logs | Local elevated credentials must remain ephemeral and redacted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05 | Spoofing / Elevation | RLS/RPC claims | mitigate | Real Auth JWTs plus SQL claim simulation, two-owner denial, narrow grants. |
| T-01-08 | Tampering | RPC/trigger side effects | mitigate | Exact effect counts and rollback assertions after every denied/failed call. |
| T-01-11 | Information Disclosure | tokens/errors | mitigate | In-memory local env, no token snapshots/logs, redacted response assertions. |
| T-01-SC | Tampering | test dependencies | mitigate | Existing Vitest and Node fetch only; no package added. |
</threat_model>
