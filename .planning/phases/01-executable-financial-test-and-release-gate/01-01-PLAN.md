## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Policy JSON → workflow/ruleset | Repository configuration controls whether money-bearing changes can merge or promote. |
| Lane runner → Docker/Supabase | Untrusted process failures must not be misclassified as passing assertions. |
| Test output → logs/evidence | Local tokens and sensitive values must not be emitted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | `release-policy.json` | mitigate | Exact six check identities and non-overridable classes are tested; no wildcard bypass. |
| T-01-02 | Repudiation | `release-policy.json`, receipt schema | mitigate | Version every policy/receipt and require owner, timestamps, results, and digests. |
| T-01-03 | Tampering / Information Disclosure | `run-supabase-lane.mjs` | mitigate | Local-only argv, bounded bootstrap classification, full redaction, and unconditional cleanup. |
| T-01-SC | Tampering | GitHub Actions/CLI references | mitigate | Later workflow plans pin reviewed action SHAs and Supabase CLI 2.115.0; this plan installs no package. |
</threat_model>
