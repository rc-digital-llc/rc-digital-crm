<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| JWT caller → service-role client | Elevated Storage/database access could act as a confused deputy. |
| Database path → signed URL | A substituted path or leaked token is bearer authority until expiry. |
| Uploaded bytes → trusted evidence | Malicious bytes must remain quarantined without a verified scanner decision. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-15 | Elevation | Edge admin client | mitigate | Verify Auth user and exact stored scope/grant before every admin action. |
| T-02-16 | Tampering / Disclosure | signed capability | mitigate | Server path, DB-returned target, 60-second expiry, no logs/cache, tamper tests. |
| T-02-17 | Tampering / DoS | uploads | mitigate | MIME/size allowlist, quarantine, scanner-gated customer flow. |
| T-02-SC | Tampering | dependencies | mitigate | Existing official Supabase APIs only; no package install. |
</threat_model>
