<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Browser form/export → data provider/file | Broad records or spoofed scope could leave the UI boundary. |
| Responsive state → user action | Hidden/occluded controls could cause wrong-account edits. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-20 | Spoofing / Elevation | account forms | mitigate | No editable organization/path authority; RLS authoritative. |
| T-02-21 | Information Disclosure | CSV export | mitigate | New allowlisted projection and negative field tests. |
| T-02-22 | Tampering | lifecycle UI | mitigate | No delete; explicit status/end reason and confirmation. |
| T-02-SC | Tampering | UI registry | mitigate | Installed official components only; no package or third-party registry addition. |
</threat_model>
