<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Auth JWT → PostgreSQL | Untrusted caller claims request organization/account rows. |
| Browser form → account records | Client fields could attempt to author tenant identity or delete history. |
| Definer helper → protected tables | Elevated helpers could widen access or resolve attacker-controlled objects. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing / Elevation | account RLS | mitigate | Server-derived membership/contact scope, force RLS, two-tenant claims. |
| T-02-02 | Repudiation | role/account changes | mitigate | Append-only allowlisted audit with exact actor/tenant/account/result. |
| T-02-03 | Tampering / Elevation | private helpers | mitigate | Empty search_path, schema qualification, PUBLIC revoke, catalog tests. |
| T-02-SC | Tampering | dependencies | mitigate | No package installation; existing lockfile and Phase 1 supply-chain gate remain authoritative. |
</threat_model>
