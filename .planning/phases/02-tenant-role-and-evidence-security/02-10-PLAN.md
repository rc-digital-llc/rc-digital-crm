<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Capability summary → presentation | Stale/forged browser state must not grant server authority. |
| Signed URL/query data → cache/storage/DOM | Bearer capabilities could persist after role/logout/expiry. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-23 | Elevation | canAccess | mitigate | Presentation only; every operation still crosses RLS/RPC/Edge authorization. |
| T-02-24 | Information Disclosure | persisted cache | mitigate | Explicit dehydrate exclusion, auth-transition purge, focused tests. |
| T-02-25 | Disclosure / Spoofing | evidence panel | mitigate | No raw paths; transient 60-second capability; exact purpose/server command. |
| T-02-SC | Tampering | UI components | mitigate | Repository-owned components only; no new dependency. |
</threat_model>
